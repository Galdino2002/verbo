# Verbo 📖

Verbo é uma plataforma de aprendizado bíblico gamificada construída com React + TypeScript + Vite.

## Estado atual

O MVP frontend funciona sem backend e usa localStorage para sessão e progresso.

### Incluído
- Login visual com validação local
- Dashboard/Home
- Jornada de aprendizado
- Lições interativas
- XP e sequência
- Biblioteca de livros da Bíblia
- Revisão de versículos
- Conquistas
- Perfil e estatísticas
- Desafio bíblico
- Layout responsivo

## Executar

```bash
npm install
npm run dev
```
